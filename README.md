# Guitar Library

自分専用のコード譜・TAB譜ライブラリ。ログイン不要・サーバー不要・完全ローカル保存(IndexedDB)の個人用PWAです。

## 公開してiPhoneで使う(推奨: GitHub Pages)

1. このフォルダの中身(index.html / style.css / app.js / manifest.json / sw.js / icons/)をGitHubリポジトリにアップロード
2. リポジトリの Settings → Pages で公開(ブランチをルートで指定)
3. 発行されたURL(例: `https://ユーザー名.github.io/リポジトリ名/`)をiPhoneのSafariで開く
4. 共有ボタン → 「ホーム画面に追加」

これでホーム画面のアイコンをタップするだけでアプリとして起動します。

## 注意

- データは端末のブラウザ内(IndexedDB)にのみ保存されます。他の端末とは同期されません。
- iPhone Safariは長期間アクセスがないサイトのデータを消すことがあるため、設定画面の「書き出す」で定期的にバックアップ(JSON)を保存してください。
- コードのタップでダイアグラムが出るのは、よく使う開放コード・簡単なバレーコードのみです(未対応のコードは名前のみ表示)。

## 再生しながらコードを追う「再生」タブ

曲の編集画面で音源ファイル(mp3/wavなど)を登録すると、曲ページに「再生」タブが追加されます。

- 音源を再生しながら、現在弾くべきコードを画面中央に大きく表示します(コードダイアグラム付き)
- 画面下部にコード進行を横並びで表示し、現在位置を自動でハイライト・スクロールします
- 次に弾くコードも小さく表示され、コードチェンジの準備ができます
- コード譜のテキストに「0:09　C」のような「時刻 + コード」の行があると、その時刻に自動で同期します(「音源から自動検出」を使うと自動的にこの形式になります)
- 進行バーのコードを長押し(またはPCでは右クリック)すると、その場でコード名を修正できます
- 再生速度は 0.5x〜1.5x の間で切り替えられます

時刻付きの行が無い曲では、再生タブに音源プレイヤーだけが表示され、コード表示の自動ハイライトは行われません。従来通り「コード譜」タブでテキストのコード譜を確認できます。

**注意:** 音源ファイルもIndexedDBに端末内保存されます。大きなファイルを多数登録すると端末のストレージを圧迫する可能性があるため、長い曲や高音質すぎるファイルは避け、必要に応じて設定画面の「書き出し」でバックアップを取ってください(書き出したJSONにも音源データが含まれます)。

## 音源からコードを自動検出

「曲を追加/編集」画面のコード譜欄にある「🎵 音源から自動検出」から、MP3/WAVなどの音源ファイルを選んで解析できます。

- 解析は端末のブラウザ内だけで行われ、音源はどこにも送信されません(FFT・クロマ解析・コードテンプレート照合による推定)
- 数分の曲でも数秒〜十数秒ほどで完了します(先頭6分までを解析対象とします)
- 結果は「開始時刻 + コード名」のリストで表示され、▶ボタンでその場所を聴き直しながら、コード名を自分で修正したり不要な行を削除したりできます
- 「コード譜に反映する」を押すとコード譜欄にタイムスタンプ付きで挿入されるので、そこからいつも通り自由に編集して保存してください

### 精度についての注意

- 単純なコード進行(オープンコード中心)ほど精度が高く、複雑な和音・転調・ソロ演奏などは誤検出が増えます
- テンポやリズムの区切り(小節線)は判定しないため、結果は「時刻+コード」の形式です。小節に整えるのは手動で行ってください
- 検出できるのはメジャー/マイナーの三和音までです(7th等の細かい違いは自分で修正してください)
- あくまで下書き作成の補助なので、必ず自分の耳で確認・修正してから使ってください
